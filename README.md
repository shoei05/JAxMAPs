# JAxMAPs — JACSIS／JASTIS 知見マップ

JACSIS（Japan COVID-19 and Society Internet Survey）と JASTIS（Japan Society and new Tobacco
Internet Survey）から出た論文を、**曝露とアウトカムの関連**という軸で俯瞰するための索引です。

👉 **[マップを開く](https://shoei05.github.io/JAxMAPs/)**

## これは何か

- 論文 **299 本**（資料323点を正規化。補足資料6点は論文数に含めない）
- 概念 **42 領域**、関連ペア **116 組**
- 各論文について、調査名・研究デザイン・対象集団・問いの型・主曝露の領域・主アウトカムの領域・
  調査波・関連する領域のタグを持つ

ネットワーク図のノードは概念、線は「その論文が主曝露と主アウトカムとして扱った組合せ」です。
円の大きさと線の太さは**論文数だけ**を表します。

## 読むときの注意

この索引には限界があります。数字を独り歩きさせないために、先に書いておきます。

1. **線は解析上の役割であって、因果関係ではありません。**
2. **線が無い組合せは「主分類の登録なし／詳細未確認」です。**「その研究が存在しない」という意味では
   ありません。各論文から主曝露・主アウトカムを1つずつしか取っておらず、副次解析や層別解析は
   見ていません。
3. **分類の大半は機械判定です。** 人が本文で確認したのは調査波の34件だけで、主曝露・主アウトカムの
   判定は一つも人手確認を経ていません。各論文の「確認状態」を見てください。
4. **結果（オッズ比・信頼区間などの推定値）は収載していません。** 数値は自動生成せず、原著で
   確認してください。
5. **書誌が未整備の論文が約30本あります。** Crossref で帰属を確認できず、ファイル名を仮のタイトルと
   して表示しています。画面上で「書誌未整備」と表示されます。
6. 論文数は資料数ではありません。同じ論文のPDFが別名で複数ある例が16組ありました。

## どう作ったか

1. コーパスのPDF 323点から全文を抽出し、冒頭とMethods・Resultsを切り出す。
2. 型付き判断API（[Jev / TypeSafe System One](https://typesafe.ai/)）に渡し、1論文あたり65スロットを
   埋める。**このAPIは文章を生成せず、用意した選択肢と確率だけを返します。**
3. 各候補DOIを Crossref に照会し、第一著者姓・発行年・誌名が本文1ページ目に現れるかで
   **そのDOIがその資料自身のものか**を確認してから論文を同定する。
4. 判定できない場合は「該当なし」に変換せず、`role_absent`（役割自体がない）／
   `concept_unmapped`（概念は分かるが語彙にない）／`not_determined`（本文から確定できない）に
   分けて残す。

調査波の判定は、ファイル名に人が書き込んだ調査名・調査波を独立の対照として評価しました
（完全一致 178/181）。ただしその対照自体に誤りがあった例が36件あり、本文を読んで逐語引用つきで
正解を作り直しています（`data/gold_waves_verified.json`）。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | ビューア本体。データを埋め込んであるのでローカルで開くだけで動きます |
| `app.js` / `style.css` | 描画と体裁。力学配置は自前実装で、外部ライブラリを使いません |
| `data/jaxmaps.json` | 論文・概念・関連ペアのデータ |
| `data/schema.json` | 語彙（領域42、対象集団12、デザイン6、問いの型7、役割未解決3、表示グループ9） |
| `data/gold_waves_verified.json` | 本文で確認した調査波36件。逐語引用つき |

**論文PDFは含みません。** 書誌情報（タイトル・著者・誌名・発行年・DOI）と、こちらで付けた
分類だけを置いています。
