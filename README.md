# JAxMAPs — JACSIS／JASTIS 知見マップ

[年度別の質問を開く](https://shoei05.github.io/JAxMAPs/#survey) · [概念マップ](https://shoei05.github.io/JAxMAPs/)

調査票の質問と研究論文を行き来できる、外部ライブラリ不要の閲覧アプリです。

- JASTIS **2015–2026**、JACSIS **2020–2025年度**。2024・2025年度はそれぞれ2024–2025・2025–2026年の調査。
- 公開収載 **1,884設問群・11,630項目**、収載のある調査波 **19**。同じ番号でも本文が異なる版は保持し、同一設問内の完全一致項目は統合。
- **300論文**、42概念、115組の主曝露・主アウトカムの関連、聖路加の表に登録された24尺度。
- 年度一覧、全文・選択肢・変数名検索、分類・尺度での絞り込み、他年度の同文設問の比較、設問保存、CSV/JSON出力。
- 論文の調査年・調査別絞り込み、関連行列、鮮明なSVGでの概念マップ保存。

## 調査票の出典

[JACSIS公式のデータ利用案内](https://jacsis-study.jp/dug/index.html)と[JASTIS公式サイト](https://jastis-study.jp/)の公開調査票を使用します。公式公開DOCX 26本から設問を抽出し、既存カタログの公開用資料を合わせています。詳細画面で出典を切り替え、公式資料へのリンクと原文全文を確認できます。

質問・下位項目・回答選択肢を収載しています。**回答者の個票、内部メモ、共有禁止版、論文PDFは公開しません。** 非公開版を含む研究用データはこのリポジトリにはありません。

現在、JACSIS 2021 妊産婦票、JACSIS 2022 妊産婦票は公開可能な質問本文を未収載として表示しています。 DOCXの図中の文字は未OCRです。公開原票で非公開とされた尺度本文は補いません。

## 聖路加での共同整理

山﨑あかりさん（2024年）・山崎友紀乃さん（2025年）が作成した、聖路加国際大学公衆衛生大学院のJACSIS2020/2021バリデーション表を活用しています。分類・尺度名・原表のグレード・根拠文献を引き継ぎ、原表との直接照合と他年度への文言一致による参照を区別します。

2026-09-22にExcel原本を再点検し、尺度名を空欄へ無制限に補完していた旧処理を修正しました。表示項目数は原表で尺度名が明示された行数です。尺度の標準項目数・採点法・当該調査での妥当性を保証するものではありません。尺度の領域対応は既存の機械判定を引き継ぎ、訂正履歴も保持しています。

## 数字と比較の読み方

- 同文の設問は、文字幅と空白を正規化した本文一致で検索します。対象条件、下位項目、選択肢の同等性は別途確認が必要です。
- 項目は出典ごとに異なる場合があります。公式公開版を優先表示し、複数版の選択肢を一つに混ぜません。原文の機械抽出には未確認部分があるため、分析前に公式原本を確認してください。
- 関連論文は概念の一致による案内です。その論文がその設問を実際に使用したという意味ではありません。
- 関連の線とセルは主曝露・主アウトカムとして分類された論文数であり、因果関係・効果量・有意性を示しません。空欄は未研究を意味しません。
- 論文の確認状態は調査波の本文確認と機械分類を区別します。効果推定値・信頼区間は未収載です。

## ファイル

`index.html` を開くだけで利用できます。質問データは `data/survey-data.js`、機械可読版は `data/survey.json`。論文・概念は `data/jaxmaps.json`、尺度は `data/scales.json` にあります。`release-manifest.json` に各ファイルのSHA-256を記録しています。
